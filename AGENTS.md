# Atoms - A collection of code snippets to copy and paste into your projects

This repository contains a collection of code snippets that can be easily copied and pasted into your projects. These snippets cover a wide range of programming languages and topics.

# Repo Layout

The repository is organized as follows:

- `<topic>` is the main category, such as language, framework, or tool names.
- `<subtopic>` is a more specific category within the main topic, such as a specific library, feature, or use case.
    - sub topics could be nested further if needed.

For example: `django/reorder-django-choices/reorder.py` would be a snippet for reordering Django choices.

Some other snippets could come with additional files for testing, documentation, or examples.

# Agent Working Rules

- Keep in mind that the subtopic directory is the root for the snippet we are working on. So, from that folder onwards is related to that snippet.
- Keep it minimal, no dependencies when possible.
- Each snippet should be self-contained as much as possible.
- If a snippet requires additional files, they should be included in the same directory.
